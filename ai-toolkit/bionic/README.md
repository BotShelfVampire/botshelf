# LM Studio Bionic — practical starter pack

Bionic is LM Studio's agent for open models. It can work with documents and code, and a project can be pointed at a local codebase so the agent can search files, edit, run commands, and use Git.

You can choose:
- local models on your computer
- remote local models through LM Link
- supported cloud open models when you intentionally want stronger compute

Official docs:
- https://lmstudio.ai/docs/bionic
- https://lmstudio.ai/docs/bionic/quick-start
- https://lmstudio.ai/docs/bionic/models

## BSV assets

- `project-worker-template.md` — paste into a new Bionic coding/document session
- `context-compressor-template.md` — use a local model to reduce repeated project context without turning the local agent into final reviewer

The point is not “use local AI for everything.” The point is to route cheap, verifiable work to local/open models and preserve frontier reasoning for tasks that need it.
