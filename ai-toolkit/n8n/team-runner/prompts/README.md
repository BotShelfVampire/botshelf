# prompts/

Put one system prompt per task here as `<task>.txt` (for example `doc-review.txt`).

Copy it from the task's full-text page in the BSV Library (free email verification), listed in `../tasks.json` as `full_text_page`. The runner reads the `OUTPUT:` list at the end of the prompt to check that every required section is present.

Prompt bodies are not stored in this starter.
