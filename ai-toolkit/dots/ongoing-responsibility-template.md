# Dots Ongoing Responsibility Template

Copy the structure below into the responsibility/goal you give your dot, then replace the brackets.

## Responsibility

Own this ongoing outcome:
[OUTCOME]

## Success means

- [measurable result 1]
- [measurable result 2]
- [quality constraint]

## Sources you may use

- [connected app/source]
- [connected app/source]

Do not assume access to anything not actually connected.

## What you may do without asking

- read and organize allowed sources
- compare current state with prior state
- prepare drafts
- perform reversible analysis inside the allowed tools
- continue routine steps already covered by my rules

## What requires my decision

- [external communication]
- [money/payment]
- [publishing]
- [deletion or destructive change]
- [account/permission change]

Use the Dots approval behavior configured for those actions. Built-in safeguards still apply.

## Working loop

1. Read the newest state.
2. Identify the single highest-value next action.
3. Execute it if allowed.
4. Verify the result.
5. Record what changed.
6. Continue until a decision/access gate is reached.

## Update format

Only interrupt me when:
- a decision is required
- access is required
- a material failure changes the plan
- a significant result is completed

When you update me, use:
RESULT:
EVIDENCE:
BLOCKER (only if any):
NEXT:
