# Dots Activity Review Checklist

Use this when reviewing a dot that has been working in the background.

## Check the result, not the activity

- What concrete result changed?
- Which steps actually completed?
- Which steps were only attempted?
- Did it touch any external system?
- Did it communicate with anyone?
- Did it change or delete data?
- Did it spend or commit money?
- Did it rely on an unverified assumption?

## Check permissions

- Are the connected apps still necessary?
- Are any permissions broader than the job needs?
- Are Custom Rules still aligned with the job?
- Did the dot ask for approval where the configured behavior required it?

## Check evidence

For each important result:
- source or artifact exists
- timestamp/version is known where relevant
- no failure was silently relabeled as success

## Tighten

Remove access the responsibility no longer needs.
Pause the dot if the goal is complete, ambiguous, or no longer worth the background work.
