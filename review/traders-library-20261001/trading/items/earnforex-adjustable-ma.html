Adjustable MA

Compare moving-average crossover rules in MetaTrader’s tester. A configurable teaching EA for testing, not a profitable-system claim.

移動平均線の交差条件を、MetaTraderのテスターで比較する学習用EAです。

Research source, not a live-ready EA. Read all known issues before any demo test.

研究用の原本です。実運用向けのEAではありません。デモ検証の前に既知の問題を確認してください。

What it does

仕組みと使い道

Two moving averages generate cross-based trades. Their parameters and some position-management settings can be changed to compare variations.

2本の移動平均線の交差を使って売買します。移動平均線の条件と一部の取引管理設定を変更し、違いを比較できます。

Settings to understand first

最初に確認する設定

Install as an EA in the matching MT4 or MT5 terminal. Test one parameter change at a time, include transaction costs, and inspect individual trades before comparing summary results.

MT4・MT5に合う版をEAとして導入します。一度に変える設定を一つに絞り、取引コストを入れ、集計値だけでなく個別の売買履歴も確認します。

What to watch out for

注意点と制約

The author explicitly states that this EA is not profitable and should be used only on a demo account. Optimizing a historical result does not establish a future advantage.

作者が「収益性がない」「デモ口座でのみ使用」と明記しています。過去成績が良くなる設定を探しても、将来の優位性が確認されたことにはなりません。

Install, inspect, then test

導入から検証まで

  1. Open the original author repository below and read its current LICENSE and installation instructions. Get the matching source folder or repository ZIP from that author; no source package for this item is mirrored by BSV.
  2. In the matching desktop terminal choose File → Open Data Folder. Copy this EA source under MQL4/Experts or MQL5/Experts. Preserve include/folder structure if the author’s package has it.
  3. Open the matching MetaEditor, compile the main source, and resolve errors and missing dependencies. Check the tool-specific notes before enabling any permission. Do not enable DLL or external-web access simply to make an error disappear.
  4. Use Strategy Tester and an isolated demo account with no other positions first. Confirm entries, exits, order filters, costs, restart behavior and failures. Reading source is not a substitute for those checks.
  1. 下の原作者リポジトリで、現行のLICENSEと導入手順を読みます。対応するソースフォルダーまたはリポジトリZIPを原配布元から取得します。この項目のソース一式はBSVでは複製配布していません。
  2. 対応するデスクトップ版で「ファイル→データフォルダを開く」を選び、EAをMQL4/ExpertsまたはMQL5/Expertsへ置きます。作者のパッケージに付属フォルダがある場合は階層を崩しません。
  3. 対応するMetaEditorで本体をコンパイルし、エラーと依存不足を確認します。各ツールの注意点を読み、エラーを消す目的だけでDLLや外部通信を許可しないでください。
  4. まず他のポジションがないテスター・隔離したデモ口座で、新規注文・決済・対象の絞り込み・コスト・再起動・失敗時の処理を確認します。ソースを読むだけではこれらの実行確認の代わりになりません。
