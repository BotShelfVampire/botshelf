Price Channels

Backtest a long-only return inside an EMA/ATR channel.

EMAとATRのチャネル内へ戻る動きを買いのみで検証。

What it does

仕組みと使い道

Builds a channel around EMA(21) using ATR(14) times two. A close crossing above the lower band requests a long. Crossing the upper band or elapsed signal time requests an exit.

EMA21を中心にATR14の2倍幅のチャネルを描きます。終値の下限上抜けで買い、上限上抜けやシグナル後の経過本数で決済を要求します。

Settings to understand first

最初に確認する設定

EMA length, Holding Period and Multiplier are inputs. ATR length is fixed at 14 in this source.

EMA期間、保有期間、倍率が設定項目。ATR期間は原本のコード内で14に固定されています。

What to watch out for

注意点と制約

No short entries or stop-loss. The comment says days, but the holding parameter counts chart bars.

売りエントリーと損切りはありません。コメントはdaysですが、保有期間はチャートの本数です。

Install, inspect, then test

導入から検証まで

  1. Download the source-and-license ZIP and extract it. Keep LICENSE.txt with the source when you share a copy.
  2. Open a TradingView chart, open Pine Editor, and create a blank script. Paste the chosen Pine source, preserving its version line. The .ps files in this collection are Pine Script examples, not PowerShell programs.
  3. Save and use Add to chart. For Pine v3/v4 code, try the original version first; use TradingView’s official migration tools sequentially if conversion is necessary. Compilation has not been performed by BSV.
  4. Open Inputs and Style. Reproduce a small historical example, then use replay and an isolated paper workflow to observe how the current bar changes. A plotted indicator does not automatically place orders.
  1. ソースとライセンスのZIPを取得して展開します。再配布する際はLICENSE.txtを原本と一緒に保持します。
  2. TradingViewのチャートでPineエディタを開き、空のスクリプトへ貼り付けます。先頭のバージョン指定を残します。このライブラリの.psはPine Scriptで、PowerShell用ではありません。
  3. 保存してチャートに追加します。Pine v3/v4はまず原版のまま確認し、変換が必要なら公式の移行機能で段階的に移行します。BSVではコンパイルを実施していません。
  4. 入力とスタイルを設定し、小さな過去例を再現します。リプレイと隔離したペーパー環境で未確定バーの変化を観察します。インジケーターの表示だけで自動発注されるわけではありません。

//@version=6
strategy("Price Channels", overlay=true)
fairvalue = input.int(21, 'Exponential Moving Average', minval=1)
hold = input.int(30, 'Holding Period', minval=1)
mult = input.float(2, 'Multiplier', minval=0.1, step = 0.1)
atr = ta.atr(14)
ma = ta.ema(close, fairvalue)

resistance = ma + (atr * mult)
support = ma - (atr * mult)

plot(ma, 'Average', color=#AAAAAA88)
plot(support, 'Support', color=#00DD0088)
plot(resistance, 'Resistance', color=#DD000088)

if ta.crossover(close, support)
    strategy.entry("Long", strategy.long)
if ta.barssince(ta.crossover(close, support)) > hold
    strategy.close("Long", comment="close 30 days")
if ta.crossover(close, resistance)
    strategy.close("Long", comment="close overvalued")
