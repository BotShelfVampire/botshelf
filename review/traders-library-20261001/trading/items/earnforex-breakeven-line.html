Breakeven Line

See the combined break-even reference for multiple trades on the same symbol.

同じ銘柄で複数の建玉を持つ際に、合算した建値の目安を確認する指標です。

What it does

仕組みと使い道

The indicator displays a cumulative break-even price together with distance, total profit/loss, volume and trade count.

合算の建値とそこまでの距離、損益、総ロット、取引数などを表示します。

Settings to understand first

最初に確認する設定

Compare a simple demo position set with a manual weighted calculation. Verify how the author’s current version handles costs and mixed long/short exposure.

単純なデモ建玉で加重計算と比較し、手数料・スワップ・買い売り混在時を現行版がどう扱うか確認します。

What to watch out for

注意点と制約

A displayed line is not an instruction to hold until recovery. Equal opposite exposures and cost assumptions require careful interpretation; this indicator does not move stops.

建値まで待つべきという売買指示ではありません。同量の両建てやコストの扱いには注意が必要です。ストップを移動するEAではありません。

Install, inspect, then test

導入から検証まで

  1. Open the original author repository below and read its current LICENSE and installation instructions. Get the matching source folder or repository ZIP from that author; no source package for this item is mirrored by BSV.
  2. In the matching desktop terminal choose File → Open Data Folder. Copy this indicator source under MQL4/Indicators or MQL5/Indicators. Preserve include/folder structure if the author’s package has it.
  3. Open the matching MetaEditor, compile the main source, and resolve errors and missing dependencies. Check the tool-specific notes before enabling any permission. Do not enable DLL or external-web access simply to make an error disappear.
  4. Use a demo chart and a small, known price sample. Compare plots, update timing, missing history and alert behavior. This indicator is not represented as an order-entry system.
  1. 下の原作者リポジトリで、現行のLICENSEと導入手順を読みます。対応するソースフォルダーまたはリポジトリZIPを原配布元から取得します。この項目のソース一式はBSVでは複製配布していません。
  2. 対応するデスクトップ版で「ファイル→データフォルダを開く」を選び、インジケーターをMQL4/IndicatorsまたはMQL5/Indicatorsへ置きます。作者のパッケージに付属フォルダがある場合は階層を崩しません。
  3. 対応するMetaEditorで本体をコンパイルし、エラーと依存不足を確認します。各ツールの注意点を読み、エラーを消す目的だけでDLLや外部通信を許可しないでください。
  4. デモのチャートで、確認しやすい少量の価格履歴を使います。描画、更新タイミング、履歴不足、通知の挙動を照合します。この指標を発注システムとは表示していません。
