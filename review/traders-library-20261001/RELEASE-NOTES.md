# Traders Library — reviewable build, 2026-10-01

Name: Traders Library / トレーダーズライブラリ. Source access is free.

Actual catalogue: 75 distinct programs. 35 have BSV source ZIPs; 40 are clearly
labelled links to source maintained by the original publisher. Bundled source:
36 files, including one EA's separate MT4 and MT5 versions. These variants do not
inflate the product count.

Types: 52 indicators, 3 Pine strategies, 10 entry/scheduled-order EAs,
8 trade-management EAs, 1 one-shot script and 1 development template.
Not every EA is an autonomous entry strategy; individual explanations make the
intended function and required manual setup explicit.

Built: searchable EN/JA catalogue, platform/type/use/license/source filters,
local-only saved items, 75 item pages, five original setup/selection/testing/
license guides, original-source display, full-license copy helper, individual
ZIPs, machine-readable provenance, sitemap, and a scoped homepage category.

Actual offline QA passed. See tests/qa-report.json for counts and limitations.
The own-document browser tests cover desktop and 320/390px widths, all item
routes, language and search, source actions and malformed route handling.
They are not real HTTP/deployment or trading tests.

Production status: this package does not establish that the BSV homepage or
live site has been updated. The complete current production source and the
normal deployment path are required for safe additive integration.

Earlier references to a “100-item ZIP” and unrelated test totals are superseded:
that package was not found and its attachment delivery failed. Only the files,
