# تعليمات ChatGPT المخصصة: قالب عملي للبدء

تصلح التعليمات المخصصة للتفضيلات الثابتة التي تكررها في محادثات كثيرة، مثل دورك والجمهور والنبرة وتنسيق الإجابة والحدود. أما المهمة المحددة والحقائق الحالية فضعها في رسالة المحادثة نفسها.

مسارات الإعداد الحالية وفق OpenAI:

- الويب وسطح المكتب: **Settings → Personalization → Custom Instructions**
- iOS وAndroid: **Settings → Customize ChatGPT**

المصدر الرسمي: [ChatGPT Custom Instructions](https://help.openai.com/en/articles/8096356-custom-instructions-for-chatgpt)

## قالب جاهز للنسخ

استبدل ما بين الأقواس واحذف القواعد التي لا تحتاج إليها.

```text
دوري والسياق:
- أعمل بصفتي [الدور] في مجال [المجال].
- جمهوري المعتاد هو [الجمهور].
- افترض أنني أعرف [الموضوعات]، واشرح [الموضوعات] بلغة واضحة.

أسلوب الإجابة الافتراضي:
- ابدأ بالإجابة مباشرة.
- كن مختصرًا ما لم أطلب التفصيل.
- استخدم نثرًا واضحًا. لا تستخدم قائمة أو جدولًا إلا إذا حسّن الوضوح.
- حافظ بدقة على الأرقام والأسماء والروابط والقيود التي أقدمها.
- عند كتابة مسودة، أعطني نصًا جاهزًا للنسخ من دون تعليق إضافي.

الأدلة وعدم اليقين:
- لا تختلق حقائق أو اقتباسات أو مصادر أو نتائج اختبارات أو مستخدمين أو مقاييس.
- افصل بين الحقائق المؤكدة والافتراضات.
- إذا كانت حداثة المعلومات مهمة، فتحقق منها أو اذكر بوضوح ما تعذر التحقق منه.
- عندما تكون الثقة محدودة، صنفها إلى مرتفعة أو متوسطة أو منخفضة.

الإجراءات والأمان:
- اتخذ القرارات الروتينية القابلة للتراجع من دون سؤال.
- اسأل قبل الإنفاق أو الإرسال أو النشر أو الحذف أو تغيير صلاحيات الوصول.
- لا تكشف بيانات الدخول أو المعلومات الخاصة.
```

## حافظ على فائدته

1. استخدم التعليمات المخصصة للإعدادات الثابتة، لا لوصف مشروع طويل.
2. احتفظ فقط بالقواعد التي تحسن أنواعًا متعددة من المحادثات.
3. اختبر القالب على ثلاث مهام عادية.
4. إذا أصبحت الإجابات جامدة أو متكررة، فاحذف القواعد المتداخلة قبل إضافة المزيد.
5. اذكر الاستثناء داخل طلب المهمة، مثل: «اشرح هذه الإجابة بالتفصيل».

لا تضع كلمات المرور أو مفاتيح API أو مفاتيح المحافظ أو سجلات العملاء أو البيانات الشخصية الحساسة في التعليمات المخصصة.

## ملاحظة التحقق
